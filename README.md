
# GTA-SAN-ANDREAS-EXTERNAL
An external cheat for offline `GTA: San Andreas`.

This is a program that attaches to `GTA: San Andreas` and changes values in it's memory to achieve things you wouldn't be able to achieve in the normal gameplay of the game. I personally didn't play any of those online `GTA: San Andreas` mods and lobbies, so I am not certain that this cheat will work on online mods. If it works, just don't ruin other people's fun, and I'm totally OK with that 😄

I tried my best to keep the code **clean**, **understandable** and **modifiable**.

Compile it with `g++ -o myCheat gtasanexternal.cpp -mwindows` and you're good to go! Have fun.
